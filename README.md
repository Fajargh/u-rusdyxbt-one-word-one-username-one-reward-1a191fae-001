Entry for the make.fun competition **One Word, One Username, One Reward**
([bounty page](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae)).

## What it does

`main.py` writes the entrant's own make.fun username — one word, no
explanation — to `/output/entry.txt`. The entry is:

```
hazel-harbor-36
```

## The gate

The entry must be UTF-8 text of 1 to 30 characters, a single word, not
only whitespace. `main.py` validates this before writing: 15 characters,
one word, no spaces.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
